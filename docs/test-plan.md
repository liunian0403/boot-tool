## B. Windows 真机手工验收

### B1. AC1 — 开机时刻与权威来源 ≤ 1 秒

对以下三种场景各执行一次：

1. 冷启动 / 重启（场景 1、2）；场景 3 为睡眠 ≥30 分钟后唤醒。
2. 场景完成后运行 `systeminfo | findstr /C:"系统启动时间"`（英文系统 `System Boot Time`），并与工具显示的"开机时间"对比。
3. 任务管理器 → 性能 → CPU → 底部"正常运行时间"与工具"已开机"对比（秒级）。
4. 判定：两者显示值差 ≤ 1 秒。

### B2. AC2 — 时长精度与 7 天无漂移

1. 记录某时刻工具显示与权威来源显示（任务管理器"正常运行时间"）。
2. 机器连续运行 7 天（不关机，允许睡眠），再次对比。
3. 判定：任意时刻差 ≤ 1 秒，7 天后无累积偏差。
4. 补充：对照 `systeminfo` 启动时间每 24 小时抽查一次。

### B3. AC3 — 睡眠 4 小时后唤醒

1. 记录睡前"已开机"值 T1。
2. 睡眠 4 小时，唤醒。
3. 判定：唤醒后显示 ≈ T1 + 4h（差 ≤ 1 秒）、开机时刻无跳变、界面数值连续无闪烁重置。

### B4. AC4 — 断电不损坏累计数据

**本期 N/A**：P0 无持久化数据（见 `docs/design.md` §8 决策 2）。本条随 P1"累计开机时长"实现时执行：强制断电重启后累计值不损坏、不重复累加。

### B5. AC5 — 时区切换

1. 设置 → 时间和语言 → 时区改为另一个（如 UTC+8 → UTC-5），观察工具。
2. 判定："开机时间"显示变为新时区的正确墙钟时刻；"已开机"值不跳变。
3. 恢复原时区，再验一次。（夏令时切换如条件允许同样执行）

### B6. AC6 — 启动速度与资源占用（参考目标，回填基线）

1. 启动耗时：双击 exe 到首屏出数，目测/秒表，判定 < 3 秒。
2. 资源：任务管理器 → 详细信息/性能，记录空闲 CPU 占用与内存（私有工作集），连续观察 5 分钟。

### B7. AC7 — 中英文系统

1. 中文系统：界面为"开机小助手 / 已开机：3天4小时5分6秒"。
2. 英文系统（或 Settings 区域语言切英文后重开）：`Boot Assistant / Uptime: 3d 4h 5m 6s`。
3. 判定：两种语言下功能、数值一致，无乱码、无截断。
4. 回归：语言切回中文再验。

### B8. 补充用例（超出 AC，建议执行）

- 高 DPI（150%/200% 缩放）下窗口文字不模糊、不越界。
- 拖动/最小化/还原窗口，数值持续刷新。
- 连续运行中 NTP 校时（可手动改系统时间触发）："已开机"不受影响。
- 关闭再重开工具：显示值一致。
- 无控制台黑窗闪现（`-H=windowsgui` 验证）。
